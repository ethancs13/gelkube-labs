    04

    The GitOps loop

    Git is the boss. Push a change and Argo CD pulls it in; change the cluster by hand and Argo CD puts it back. Time is sped up: 1 second here ≈ 1 minute for real.

    Git says2 pods · "hello from git"
    Cluster has2 pods · "hello from git"

    Status: Synced Git and the cluster match.

    App of apps

    One file applied by hand, ever: root.yaml. It watches a folder of Applications; each of those watches its own app.

    root ← k8s/argocd/root.yaml ├─ hello-gelkube plain manifests (k8s/apps/hello-gelkube) ├─ jellyfin Helm chart 3.7.0 + values.yaml ├─ intel-gpu-plugin Intel's repo v0.37.1 + kustomize patch ├─ adguard-home plain manifests ├─ tailscale-operator Helm chart 1.104.7 ├─ argocd-ingress Tailscale Ingress → argocd └─ tailnet-ingresses Tailscale Ingresses → jellyfin, adguard

    Which app do I refresh? The one whose folder changed. root only notices apps being added or removed.
